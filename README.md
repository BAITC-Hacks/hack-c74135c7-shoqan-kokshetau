# shoqan-kokshetau
Hackathon team repository for Shoqan

## Shoqan — толық MVP

Node.js 24+ және Node ішіндегі SQLite. Сыртқы npm кітапханалары қажет емес.
Жобаны Нұрболат жалғыз әзірлейді: сервер, API, деректер, OpenAI интеграциясы және интерфейс.
Сервер мен интерфейс арасындағы келісім: [docs/contract.md](docs/contract.md).

### Іске қосу

```powershell
node --version
Copy-Item .env.example .env.local
# .env.local бұрыннан бар болса, оны көшіріп алмастырмаңыз.
npm.cmd run seed
npm.cmd start
```

**Сайтты ашу: http://127.0.0.1:3001/**

API: `http://127.0.0.1:3001/api`; тексеру: `/api/health`.
Браузерде `/api/tasks` емес, негізгі `/` мекенжайын ашыңыз: API жолы тек JSON деректерін көрсетеді.
Сайт пен API бір командамен іске қосылады, бөлек frontend сервері қажет емес.
Windows PowerShell execution policy npm.ps1 файлын бұғаттаса, `npm.cmd` қолданыңыз.
Linux/macOS үшін `npm` және `cp .env.example .env.local` жарайды.
SQLite базасы бірінші іске қосылғанда автоматты жасалады: `data/app.sqlite`.
Ол қайта іске қосқанда сақталады. `seed` бес ойдан жасалған жария тапсырма мен үш
ұсыныс қосады; қайта орындау оларды қайталамайды және бар деректерді өзгертпейді.
Демо карточкалар иесінің токені: `local-demo-owner` (тек жергілікті демо үшін).

### OpenAI кілті

`.env.local` файлын өз компьютеріңізде ашып, `OPENAI_API_KEY=` мәнін толтырыңыз.
Кілтті чатқа, README-ге немесе интерфейске қоспаңыз. `.env.local` және база
`.gitignore` арқылы шығарылған. `.env.example` ішінде кілт бос.
`OPENAI_MODEL` әдепкісі — `gpt-4o-mini`; оны қолжетімді, Structured Outputs
қолдайтын модельге ауыстыруға болады.

Сервер [OpenAI Responses API Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)
арқылы кемінде үш нақтылаушы сұрақ сұрайды. Кілт жоқ, API істемейді,
12 секундтан асады немесе жауап жарамсыз болса, жергілікті сұрақтар қайтарылады.
ИИ тек сұрақ жасайды: карточка мәндері бастапқы сипаттамадан және адамның
PATCH арқылы берген жауаптарынан алынады. Сипаттама `context` өрісіне көшіріледі;
қалған белгісіз мәндер бос қалады. OpenAI-ға сипаттама мен өрістер жіберіледі,
иесінің токені жіберілмейді; сұрауда `store: false` орнатылған.

### Сайтты пайдалану және тілдер

1. Негізгі беттен тапсырмаларды іздеңіз немесе «Жаңа тапсырма» батырмасын басыңыз.
2. Мәселені сипаттап, жоба жасаңыз. «Сұрақтар алу» арқылы нақтылаушы сұрақтарды көріңіз.
3. Өрістерді толтырып, дұрыс ақпараттың растау белгілерін қойыңыз. Өзгерістерді сақтаңыз.
4. Карточканы қарап, жариялауды растаңыз. Толықтығы төмен тапсырма да жарияланады.
5. Карточка бетінде команда ұсынысын жіберуге болады.
6. «Менің жобаларым» → «Өңдеу» → «Ұсыныстарды басқару» арқылы ұсынысты қабылдаңыз не қабылдамаңыз.

Жоғарғы **ҚАЗ / РУС** батырмалары мәзір мен формалардың тілін бірден ауыстырады.
Қолданыстағы енгізілген мәтін тіл ауысқанда сақталады. Карточкаларды аудару үшін сервер
OpenAI-ға сұрау жібереді; аударма түпнұсқадан бөлек көрсетіледі. Карточка бетіндегі
«Түпнұсқа / Аударма» ауыстырғышымен салыстыруға болады. ИИ мағынаны қате аударуы мүмкін;
аударма растау белгілеріне, рейтингке немесе сақталған деректерге әсер етпейді.
Ұсыныстар мен редактордағы бастапқы мәтін автоматты аудармамен алмастырылмайды.

Кілт жоқ немесе API қатесі болса, түпнұсқа көрсетіліп, аударма қолжетімсіз екені жазылады.
Кілтті `.env.local` файлына енгізген соң серверді қайта іске қосыңыз (`Ctrl+C`, `npm.cmd start`).
Аударманың сәтті жауаптары сервер жадында сақталады (100 нұсқаға дейін); қайта іске
қосылғанда кэш тазарады. Каталогты ашу мен тіл ауыстыру OpenAI сұрауларын туғызуы мүмкін.

### Аккаунтпен кіру

Жоғарғы **«Кіру» → «Тіркелу»** арқылы атыңызды, email және 12–128 таңбалық
құпиясөзді енгізіңіз. Аккаунтқа кіргенде жаңа тапсырмалар автоматты түрде соған
байланады. Басқа браузерде дәл сол сайтқа кіріп, сол аккаунтпен авторизациядан
өтсеңіз, «Менің жобаларым» бөлімінде тапсырмаларыңыз ашылады.

Құпиясөздер SQLite ішінде salt бар scrypt хэші түрінде сақталады. Сессия cookie-і
HttpOnly, SameSite=Strict болады, 7 күнде аяқталады; «Шығу» сол сессияны жояды.
Кіру және тіркелу әрекеттері бір IP үшін 15 минутта 15 әрекетпен шектелген
(бір сервер процесінің жадында; қайта іске қосқанда лимит тазарады).
Аккаунт басқа адамның жеке жобаларын ашуға немесе өңдеуге рұқсат бермейді.
Email растау және ұмытылған құпиясөзді қалпына келтіру әзірге жоқ.

Бұрын қонақ ретінде жасалған жобалар автоматты көшірілмейді. Аккаунтқа кіріп,
қажетті жобаны «Өңдеу» арқылы ашыңыз да, **«Осы аккаунтқа қосу»** батырмасын
басыңыз. Мәтін, рейтинг, ұсыныстар және жариялау күйі сақталады, бұрынғы кілт
жұмысын тоқтатады. Ортақ демо тапсырмаларды жеке аккаунтқа қосуға болмайды.
«Менің жобаларым» карточкалары аккаунтта немесе тек браузерде сақталғанын көрсетеді.

Қонақ ретінде жасалған жобалардың иелік кілттері осы браузерде сақталады.
Редактордағы «Қолжетімділікті сақтау» бөлімінен ID мен кілтті жеке жерге көшіріп алыңыз.
Басқа браузерде «Менің жобаларым» → «Жобаға қайта кіру» арқылы қалпына келтіріңіз.
`localhost` пен `127.0.0.1` бөлек браузер қоймаларын қолданады; бір мекенжайды тұрақты қолданыңыз.
Демо карточкаларда «Демо басқаруды көру» батырмасы бар.

### Рейтинг және жариялау

Ұпай = **бос емес әрі адам растаған** өрістер салмақтарының қосындысы:

| Өріс | Ұпай |
| --- | ---: |
| Контекст және қажеттілік | 20 |
| Деректер мен материалдар | 20 |
| Күтілетін нәтиже | 15 |
| Жетістік критерийлері | 15 |
| Шектеулер | 10 |
| Пайдаланушылар | 10 |
| Байланысу және кері байланыс | 10 |

0–39 — «Жоба»; 40–69 — «Жұмысқа дайындалып жатыр»;
70–89 — «Дайын»; 90–100 — «Басым».
Атау ұпай қоспайды. Рейтинг компания беделін емес, тапсырманың толықтығын көрсетеді.
Жариялау үшін атау мен барлық толтырылған өрістерді растау және карточканы
адамның қарағанын көрсету қажет. Бос өрістер қалуы мүмкін; ең төмен ұпай шегі жоқ.
Өңдеу карточканы draft күйіне қайтарады; өзгерген мәнді қайта растау қажет.

### Демо және тексеру

Сервер жұмыс істеп тұрғанда екінші терминалда:

```powershell
npm.cmd run demo
```

Бұл ойдан жасалған деректермен бүкіл сценарийді орындайды: draft → нақтылаушы
сұрақтар → жауаптарды сақтау → адам растауын модельдеу → рейтингті есептеу →
жариялау → команда ұсынысы → бизнес иесінің қабылдауын модельдеу.
Нақты интерфейсте растау мен шешім жеке адам әрекеті болуы керек.
Әр demo іске қосылуы базаға бір карточка мен бір ұсыныс қосады.

```powershell
npm.cmd run check
npm.cmd test
```

Тесттер API кілтін қажет етпейді және OpenAI-ға сұрау жібермейді. Олар толық HTTP
сценарийін, төмен рейтингті каталогты, рұқсаттарды, нұсқа қайшылығын, валидацияны,
рейтингті, ИИ қателері мен артық деректерін және SQLite сақталуын тексереді.
Қосымша build қадамы жоқ; JavaScript тікелей орындалады.

### Файлдар және интерфейсті қосу

- `server/app.js`: HTTP маршруттары және сұрауларды тексеру.
- `server/domain.js`: карточка, растау және рейтинг ережелері.
- `server/store.js`: SQLite сақтау және транзакциялар.
- `server/ai.js`: OpenAI сұрақтары және резервтік режим.
- `server/seed.js`: бес демо тапсырма, үш ұсыныс.
- `server/translate.js`: карточка аудармасы және кэш.
- `server/auth.js`: аккаунттар, құпиясөз хэштері, сессиялар және кіру лимиті.
- `public/`: қазақша/орысша интерфейс, стильдер және браузер логикасы.
- `public/account.js`: кіру және тіркелу формалары, екі тілдегі мәтіндер.
- `tests/api.test.js`: автоматты тесттер.
- `tests/translation.test.js`: аударма, тілдер және сайтты беру тесттері.
- `tests/auth.test.js`: аккаунт оқшаулауы, сессиялар, ескі жобаны көшіру, лимиттер.
- `server/limits.js` және `tests/limits.test.js`: API мен OpenAI сұрауларын шектеу.
- `scripts/demo.js`: іске қосылған серверге арналған сценарий.

Кіріктірілген интерфейс [API келісімі](docs/contract.md) бойынша `fetch` қолданады.
Бір серверден ашылған сайтқа CORS баптауы қажет емес. Бөлек интерфейс серверін қолдансаңыз,
`FRONTEND_ORIGIN` интерфейстің origin мәніне дәл сәйкес болуы керек
(әдепкі `http://localhost:5173`). Иесінің токені draft жасағанда бір рет беріледі;
өзге карточкаға рұқсат бермейді. GET каталогы тек жария тапсырмаларды қайтарады.
Ұсыныстар тізімі мен қолмен шешім тек иесіне қолжетімді.

MVP жергілікті демоға арналған: әдепкі тыңдау мекенжайы `127.0.0.1`.
Email растау, құпиясөзді/жоғалған қонақ токенін қалпына келтіру және pagination әзірге жоқ.
Интернетке орналастыру алдында HTTPS, жалпы API және ИИ сұрауларының лимиттері қажет.
HTTPS ортада `COOKIE_SECURE=true` орнатыңыз және `FRONTEND_ORIGIN` мәнін нақты сайт
origin-іне өзгертіңіз. Қазіргі сессиялар бір сервердің SQLite базасында сақталады.
Жария демо токенін нақты деректерге қолданбаңыз.

### GitHub-та сақтау

Бұл репозиторий код пен нұсқаулықты сақтайды. GitHub-қа push жасау Node.js серверін
іске қоспайды; GitHub Pages бұл SQLite және серверлік OpenAI интеграциясы бар
қолданбаны толық іске қоса алмайды. Қазіргі жұмыс тәсілі — репозиторийді компьютерге
жүктеп, жоғарыдағы `npm.cmd start` командасымен ашу.

`.env.local`, SQLite деректері және `node_modules` Git-ке кірмейді.
`.env.example` тек бос кілт пен үлгі баптауларды қамтиды. Жаңа компьютерде жергілікті
баптау файлын өзіңіз жасайсыз; бұрынғы деректер автоматты түрде GitHub арқылы көшпейді.

API-ға жалпы және IP бойынша минуттық лимиттер қосылған. OpenAI-ға нақты сұраулар
әдепкіде 24 сағаттық терезеде 200 ретпен, бір мезетте 3 сұраумен шектеледі.
Оларды `AI_REQUESTS_PER_DAY` және `AI_MAX_CONCURRENT` арқылы өзгертуге болады.
Лимиттер сервер қайта іске қосылғанда тазарады; бұл ақшалай шығынның қатаң шегі емес.
Шекке жеткенде сайт түпнұсқа мәтін мен жергілікті көмекші сұрақтарды қолданады.
