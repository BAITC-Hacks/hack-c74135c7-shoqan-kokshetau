ИИ пайдаланушының орнына өрістерді толтырмайды: сұрақ қояды, жауапты адам жазады.
Карточкалардың ИИ аудармасы бөлек көрсетіледі және бастапқы деректерді өзгертпейді.
ИИ жауабының дұрыстығына кепілдік жоқ; түпнұсқа мен адам тексеруі сақталған.

## Қосылған мүмкіндіктер

- Қазақша/орысша интерфейс және карточка аудармасы.
- Аккаунт, кіру/шығу, жеке жобалар, қонақ жобасын аккаунтқа қосу.
- «Менің ұсыныстарым», мәртебе сүзгісі, бизнес түсіндірмесі.
- Сақталмаған өзгерістер туралы ескерту және жариялауға дайындық тізімі.
- Телефонға бейімделген көрініс, іздеу және сұрыптау.
- `npm.cmd run backup`: тексерілген SQLite көшірмесі.
- AI тәлімгер: екі тілдегі чат, қойындыдағы тарих, жаңа әңгіме, сұрау лимиттері.

## Әзірге жасалмаған

| Мүмкіндік | Қазіргі шектеу |

| Email растау, email арқылы құпиясөзді қалпына келтіру | Email қосылмаған; локалды терминал коды арқылы құпиясөзді қалпына келтіру бар |
| Email хабарламалары | Шешімді сайттан көреді немесе бизнес өзі хабарласады |
| Толық чат, шешімдер тарихы | Тек соңғы мәртебе мен түсіндірме сақталады |
| Каталогты беттерге бөлу | Қазір барлық жария тапсырма бір тізімде |
| Автоматты жоспарлы сақтық көшірме | Команда қолмен іске қосылады |
| Интернет хостингі, HTTPS, домен | Пайдаланушы шешімімен кейінге қалдырылған |

Бұлар бастапқы локалды MVP-ді көрсету үшін міндетті емес. Көпшілікке ашық сервиске
айналдыру бөлек кезең болады. Көшірме `.env.local` мен браузердегі қонақ кілттерін
қамтымайды; оларды жеке сақтау қажет.

## Соңғы тексеріс

- 38 автоматты тест: HTTP сценарийі, аккаунт рұқсаттары, рейтинг,
  ұсыныстар, аударма/ИИ резервтік режимі, навигация және сақтық көшірмеден оқу.
- Браузерде бөлек уақытша базамен: жоба жасау → сұрақ алу → өрістерді
  растау → сақтау → 20 ұпаймен жариялау → жоспар/мерзім/сілтемемен ұсыныс → қабылдау
  → прототип кезеңін растау → 20 команда ұпайы өтті.
- Міндетті емес профиль өрістері бос болса да ұсыныс жіберіледі. Тілді ауыстырғанда
  прогресс батырмалары мен ұпай сақталады. Тақырып және деңгей сүзгілері тексерілді.
- Қайта `seed` орындау демо шешім мен прогресті өшірмейтіні тестпен тексерілді.
- Телефон өлшеміндегі каталог және ұсыныстар бетінде көлденең тасу табылмады.
- Осы браузер сынағында ИИ кілті қосылмаған: резервтік режим тексерілді.
  Нақты OpenAI қолжетімділігі кілтке, желіге және сұрау лимитіне байланысты.
- Негізгі сервердің `/api/health` жауабы сәтті.
- Тәлімгерден нақты OpenAI жауабы алынды; екінші сұрақта тест жобасының атауы
  сақталды. Қайта жүктеу және тіл ауыстыру кезінде қойындыдағы тарих сақталды.
  AI жауаптарының мазмұны әр сұрауда өзгеруі мүмкін және қате кеңес беруі мүмкін.
